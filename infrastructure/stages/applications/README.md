# Applications Terraform Root

Owns the application-scoped layer applied after the shared cluster platform is ready.

## Ownership Boundary

This stage owns:

- ward namespaces
- application Deployments
- application Services
- application `HTTPRoute` resources attached to the shared Cilium Gateway
- application ConfigMaps, volumes, and app-specific network policies generated from the JSON model

This stage does not own:

- Cilium
- CoreDNS
- Kyverno
- Tetragon
- the control-plane namespace
- the control-plane PostgreSQL database

Those shared resources belong to the `platform` stage.

## Exposure Model

- The `platform` stage owns the shared Cilium `Gateway`.
- This stage owns per-application `HTTPRoute` resources.
- Only applications with `exposure.enabled = true`, `connectivity.internet_ingress_enabled = true`, and `service.enabled = true` get an external route.
- No Route53 records are created here. The control-plane frontend is the only workload with a dedicated DNS record.

## Direct Terraform Usage

```bash
./tfstage applications init -reconfigure -backend-config=backend.hcl
./tfstage applications plan
./tfstage applications apply
```

The second var file is generated by the backend control plane and contains the live application and ward configuration edited through the UI.
